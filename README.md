I developed a computational MATLAB model to analyze Non-Ionizing Electromagnetic Radiation (NIER) at a proposed cellular transmission site. The purpose of this project was to compute power density as a function of distance from the antenna, identify the location of maximum power density, and evaluate compliance with FCC safety guidelines. The model took into account the antenna radiation pattern where I performed linear interpolation of the Amphenol antenna's 361-point vertical radiation pattern to estimate gain at computed depression angles. It further factored in mechanical downtilt, cable losses, transmitted power, and dynamically adjusted effective antenna height based on distance to account for building obstructions. Using Effective Isotropic Radiated Power (EIRP) calculations and the far-field power density formula, the script yielded a plot and tabulated power densities at key distances.
